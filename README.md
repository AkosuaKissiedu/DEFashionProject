Luxury Item Resale Insights Dashboard

Overview

This project features interactive dashboards that analyze luxury item resales from Vestiaire Collective, using data sourced from the Kaggle API. The dashboards provide detailed insights into brand and product performance, tracking revenue by item type, category, and brand.

Live Dashboard
Access the interactive dashboard here: https://luxuryitemresaleinsights.my.canva.site/

Data Pipeline & Technology Stack
This project highlights a complete data engineering journey, covering:
Data Acquisition: Extracting data from Kaggle and storing it in AWS S3.
Data Processing & Querying: Using AWS Athena for efficient data retrieval.
Analysis & Visualization: Leveraging Microsoft Power BI for insightful data representation.
Programming Languages & Tools: SQL and Python for data manipulation and transformation.

Insights & Use Cases
The dashboard serves as a powerful tool for:
Identifying high-performing brands and product categories.
Understanding market trends in the luxury resale industry.
Making informed decisions based on real-time data analytics.

Future Improvements
Enhanced Data Sources: Integrating additional resale platforms for broader insights.
Predictive Analytics: Implementing machine learning to forecast market trends.
User Interactivity: Adding filters and drill-down capabilities for a more customized experience.
